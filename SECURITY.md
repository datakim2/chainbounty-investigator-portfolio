# Security Policy

This public repository must not contain:

- API keys, private tokens, credentials, cookies, or session artifacts;
- private investigation data or the complete Hunter database;
- personal information that is not necessary for the portfolio;
- internal filesystem paths or environment details.

Malicious URLs are not opened or rendered as part of the investigation
workflow. Public case pages link only to preserved authoritative sources and
official blockchain explorers.

Before every publication, run a secret and PII review. If a possible secret is
found, stop publication and remove or review the file before pushing.
